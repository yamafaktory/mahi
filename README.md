# mahi

> *mahi* (te reo Māori): work.

A single Rust binary that lets several engineers work together in real time with any terminal
coding agent (Claude Code, Codex, Gemini CLI, …). Peers connect directly, with no mahi server.
The full history of the work is stored encrypted in the project's own git remote.

Status: design only. See [DESIGN.md](DESIGN.md).
